# 대시보드(index) 섹션 조각 — 신규 디자인

대시보드 한 페이지를 **붙일 수 있는 단위로 9개**로 쪼갠 파일입니다.
각 파일은 **혼자 열어도 렌더링**되도록 공통 스타일을 포함하고 있습니다.

| 파일 | 섹션 | 내용 | 기존 대시보드 대응 |
|---|---|---|---|
| `dash-01-topbar.html` | 상단 네비게이션 | 로고 · 메뉴 · 업체 선택 · 할 일 배지 | 기존 헤더 |
| `dash-02-filterbar.html` | 기간 · 캠페인 필터 | 기간 프리셋 · 비교 기준 · 캠페인 ON/OFF | 기존 기간 버튼 + 캠페인 필터 (통합) |
| `dash-03-goals.html` | 목표 대비 KPI | 비용/CPA/ROAS/전환 · 예산 소진 예상일 · 작년 동기 | 🎯 목표 대비 · 💸 예산 목표 |
| `dash-04-alerts.html` | 오늘 확인할 일 | 자동 감지 3종 + **원인 분해** | 🚨 오늘 확인할 일 · 🔬 지표별 원인 분해 |
| `dash-05-insights.html` | 성과 인사이트 | 잘되고 있어요 / 확인이 필요해요 | 💡 성과 인사이트 · 🚫 비용 누수 |
| `dash-06-trend.html` | 일별 추이 | 지표 탭 · 변곡점 자동 표시 | 📈 일별 성과 3종 · 🔎 변곡점 감지 |
| `dash-07-campaign-insight.html` | 캠페인 통합 인사이트 | 캠페인별 시간대+키워드 묶음 + 제안 | 🔗 캠페인 통합 인사이트 |
| `dash-08-simulator.html` | 예산 재배분 + AI 총평 | 슬라이더 시뮬레이터 · 총평 생성 | 🔀 예산 재배분 시뮬레이터 · 🤖 AI 총평 |
| `dash-09-tables.html` | 캠페인별 · 매체별 | 표 2종 | 📣 캠페인별 성과 · 📡 매체별 성과 |

## 붙이는 순서 (권장)

데이터 의존도가 낮은 것부터 가면 중간에 막히지 않습니다.

1. **01 상단바** → 02 필터바 — 화면 뼈대. 나머지가 이 위에 올라감
2. **09 표** — 기존 데이터 그대로 쓰므로 제일 쉬움
3. **03 목표 대비** — 목표(KPI) 값이 필요. 데이터 관리에서 설정하는 값
4. **06 일별 추이** — 기존 차트 데이터 재사용
5. **05 성과 인사이트** → 07 캠페인 통합 인사이트 — 기존 계산 로직 재사용
6. **04 오늘 확인할 일** — 원인 분해(CPA→CPC/CVR) 계산이 들어가 가장 무거움
7. **08 시뮬레이터** — 마지막

## 주의

- 각 조각의 `<style>`은 파일 단독 확인용으로 중복돼 있습니다. 실제로는 공통 CSS 하나로 합치세요.
- 색 규칙: 보라(`#8b7cff`)는 선택·링크·브랜드 전용. 성과의 좋고 나쁨은 초록/주황/빨강으로만.
- 숫자는 `font-variant-numeric: tabular-nums`, 표에서 오른쪽 정렬.
- 04번의 **원인 분해**가 이번 개편의 핵심입니다. CPA 변화를 CPC와 CVR 기여도로 쪼개서 막대로 보여주는 부분입니다.
