# redesign — 새 디자인 적용본 (실제 데이터 연결됨)

이 폴더의 8개 파일은 **지금 쓰는 대시보드와 똑같이 동작**합니다.
데이터·기능은 그대로이고, 보이는 것만 새 디자인으로 바꿨습니다.

| 파일 | 화면 |
|---|---|
| index.html | 업체 대시보드 |
| overview.html | 전체 업체 |
| campaigns.html | 캠페인 |
| keywords.html | 키워드 |
| hourly.html | 시간대 |
| todo.html | 할 일 |
| input.html | 데이터 관리 |
| ab-test.html | A/B 테스트 |

## 무엇이 바뀌었나

**8개 페이지 공통**
- 배경 그라데이션 제거 → 단색
- 카드·패널 모서리를 덜 둥글게 (18/14px → 12/11px)
- 배지를 알약 모양에서 각진 모양으로
- 표 글자 12px → 13.5px, 줄 간격 넓힘, 숫자 자릿수 정렬
- KPI 라벨을 대문자 굵은 글씨에서 조용한 회색으로 낮추고 숫자를 살림

**index.html만 추가로**
- '오늘 확인할 일'을 카드 형태로 다시 그림
- CPA 변화의 원인(클릭 단가 vs 전환율)을 한 줄 글에서 **막대 두 개**로 바꿈

## 아직 안 된 것

겉모습만 바꾼 단계입니다. 화면 구조는 아직 기존 그대로입니다.
- KPI 4칸 + 목표 대비 막대
- 상단 기간 프리셋 · 캠페인 칩 필터 바
- 성과 인사이트 카드 재배치

## 되돌리는 법

각 파일 `<head>` 안의 `<style id="km-redesign-skin">` 블록만 지우면
원래 모습으로 돌아갑니다. 데이터나 기능에는 영향이 없습니다.
