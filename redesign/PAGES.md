# km-board 화면 초안 (design draft)

이 폴더의 HTML은 **디자인 시안**입니다. 숫자는 전부 예시값이고 데이터 연결은 되어 있지 않습니다.

| 파일 | 화면 | 상태 |
|---|---|---|
| `overview.html` | 1. 전체 업체 | 초안 |
| `index.html` | 2. 업체 대시보드 | 초안 (분석·판단 층 반영) |
| `campaigns.html` | 3. 캠페인 · 소재 | 초안 (인사이트·랭킹·일별 비교·제안 실행 추적) |
| `keywords.html` | 4. 키워드 · 검색어 | 초안 — **데이터 정합성 확인 후 확정 예정** |
| `hourly.html` | 5. 시간대 · 요일 | 초안 |
| `checklist.html` | 6. 체크리스트 (할 일 + A/B 테스트) | 목록·캘린더 두 가지 보기 |
| `memo.html` | 6-1. 메모 | 자유 메모, 업체 태그·고정·검색 |
| `input.html` | 7. 데이터 관리 | 초안 |
| `design-system.html` | 참고 — 색 · 글자 · 부품 기준표 | — |

## 확정된 규칙

- **글씨체**: Pretendard (jsDelivr CDN)
- **색**: 보라(`#8b7cff`)는 선택·링크·브랜드 전용. 성과의 좋고 나쁨은 초록(`#3ddc97`) / 주황(`#f5a524`) / 빨강(`#ff6b85`)으로만 표현
- **숫자**: `font-variant-numeric: tabular-nums` 고정, 표에서 오른쪽 정렬
- **기준 폭**: 1440px
- 전체 토큰은 `design-system.html` 참고

## 연결 시 주의

- 각 화면 상단의 **필터 바**(기간 프리셋 · 비교 기준 · 캠페인 ON/OFF)는 모든 화면 공통 컴포넌트입니다.
- 캠페인 칩의 **왼쪽 점은 네이버 집행 상태**, **칩 선택 여부는 화면 표시 여부**로 서로 다른 값입니다.
- `keywords.html`은 저장된 키워드 합계가 대시보드 합계와 어긋나는 문제가 확인되어, 수집기 수정 후 값을 맞춰야 합니다.

## 2026-09-10 변경

- `todo.html`(할 일) + `ab-test.html`(A/B 테스트) → **`checklist.html`(체크리스트)** 한 화면으로 합침.
  - 목록 보기: 할 일과 A/B 테스트가 섞여 나오고, A/B는 카드 오른쪽에 승패가 붙음.
  - 캘린더 보기: 마감일은 날짜 칸에, A/B 테스트의 A안·B안 기간은 가로 막대로.
  - 승패 기준: DB형 업체는 전환당 비용, B2C형은 광고 대비 매출. 양쪽 다 전환 3건 미만이면 승자를 매기지 않음.
- **`memo.html`(메모)** 추가. 저장 위치는 `config/memos` 문서 안 배열. 본문에서 고른 줄을 체크리스트 할 일로 보낼 수 있음.
- 옛 주소 `todo.html`·`ab-test.html`은 `checklist.html`로 자동 이동하는 안내 페이지로 바뀜.
- 전 페이지 메뉴에서 `할 일` + `A/B 테스트` 두 칸이 `체크리스트` + `메모`로 바뀜.

### 저장 위치를 하나로 합치지 않은 이유
할 일은 `config/todos`(팀 공용), A/B 테스트는 업체 문서의 `abTests`에 그대로 뒀다.
A/B는 업체 데이터가 있어야 비교가 되고, 할 일은 업체 없이도 만들어야 해서(공통 업무) 원래 자리가 각자 맞다.
동시 저장으로 서로 지우는 문제는 두 곳 모두 트랜잭션(저장 직전에 서버 값을 다시 읽고 내가 바꾼 것만 얹기)으로 막았다.
