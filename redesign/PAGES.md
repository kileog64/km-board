# km-board 화면 초안 (design draft)

이 폴더의 HTML은 **디자인 시안**입니다. 숫자는 전부 예시값이고 데이터 연결은 되어 있지 않습니다.

| 파일 | 화면 | 상태 |
|---|---|---|
| `overview.html` | 1. 전체 업체 | 초안 |
| `index.html` | 2. 업체 대시보드 | 초안 (분석·판단 층 반영) |
| `campaigns.html` | 3. 캠페인 · 소재 | 초안 (인사이트·랭킹·일별 비교·제안 실행 추적) |
| `keywords.html` | 4. 키워드 · 검색어 | 초안 — **데이터 정합성 확인 후 확정 예정** |
| `hourly.html` | 5. 시간대 · 요일 | 초안 |
| `todo.html` | 6. 할 일 | 초안 (알림 + A/B 비교 통합) |
| `input.html` | 7. 데이터 관리 | 초안 |
| `design-system.html` | 참고 — 색 · 글자 · 부품 기준표 | — |

## 확정된 규칙

- **글씨체**: Pretendard (jsDelivr CDN)
- **색**: 보라(`#8b7cff`)는 선택·링크·브랜드 전용. 성과의 좋고 나쁨은 초록(`#3ddc97`) / 주황(`#f5a524`) / 빨강(`#ff6b85`)으로만 표현
- **숫자**: `font-variant-numeric: tabular-nums` 고정, 표에서 오른쪽 정렬
- **기준 폭**: 1440px
- 전체 토큰은 `design-system.html` 참고

## 연결 시 주의

- 각 화면 상단의 **필터 바**(기간 프리셋 · 비교 기준 · 캠페인 ON/OFF)는 모든 화면 공통 컴포넌트입니다.
- 캠페인 칩의 **왼쪽 점은 네이버 집행 상태**, **칩 선택 여부는 화면 표시 여부**로 서로 다른 값입니다.
- `keywords.html`은 저장된 키워드 합계가 대시보드 합계와 어긋나는 문제가 확인되어, 수집기 수정 후 값을 맞춰야 합니다.
